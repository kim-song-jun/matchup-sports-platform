어드민 '공지사항·팝업·약관'을 콘텐츠 허브 `/admin/content` 한 입구로 합친다
(어드민 다이어트 3단계 · A안(3탭+문의 독립) 사용자 확정).

- 탭 3개(공지사항 | 팝업 | 약관) — 본문은 기존 화면 그대로 이식해 기능이 변하지 않아요.
  '새 팝업'·'새 약관' 버튼은 폼 상태와 묶여 있어 본문 상단 툴바로 옮겼어요.
- **문의는 독립 유지** — 인박스 성격(미확인 뱃지·딥링크 필터 5종)이라 게시물 관리와
  분리해요. 사이드바 콘텐츠 구획 4→2.
- 구 URL 3개(`/admin/notices`·`/admin/popups`·`/admin/terms`)는 `?tab=` 리다이렉트로
  남고, 팝업의 `?targetPath=` 프리필(대회 셸 홍보 팝업 만들기)은 리다이렉트·탭 전환에서
  잃지 않아요. 대회 셸 딥링크도 새 주소로 갱신했어요.
- 허브 공통 접근성 수정: 활성 탭만 마운트하므로 `aria-controls` 를 활성 탭에만 달아
  존재하지 않는 id 참조를 없앴어요(설정 허브 포함).
