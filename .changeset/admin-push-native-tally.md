어드민 수동 푸시 발송 결과에 앱 기기(APNs·FCM) 전송 건수를 웹 구독과 나란히 보여준다.

- **원인**: 발송 서비스는 웹과 앱 결과를 함께 돌려주는데 집계가 웹 칸만 옮겨 담았다. 앱 기기만
  가진 사용자에게 보내면 실제로는 폰에 배너가 뜨는데 화면에는 "구독 0건 · 푸시는 나가지
  않았어요" 로 찍혀, 운영자가 장애로 오인하거나 다시 보내게 된다(2026-09-02 alpha 실측).
- **수정**: 응답의 `push` 에 `native { devices, delivered, failed, disabled }` 를 더한다. 결과
  카드는 "웹 푸시" 와 "앱 푸시" 를 각각 한 줄로 밝히고, 어느 한쪽으로라도 나갔으면 토스트에
  "나가지 않았어요" 를 붙이지 않는다. 이 필드가 없는 예전 응답(저장된 브로드캐스트 재생 응답
  포함)은 앱 줄을 그리지 않는다.
