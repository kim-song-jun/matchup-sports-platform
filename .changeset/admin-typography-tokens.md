운영자 화면의 글자 크기를 정해진 단계로 맞췄습니다. 그동안 어드민은 글자 크기를 **세 가지 방식으로 섞어** 적고 있었어요 — 디자인 토큰, 직접 쓴 픽셀 값, 그리고 Tailwind 기본값. 그러다 보니 같은 역할인데 화면마다 크기가 달랐습니다. 예를 들어 모달 제목이 어떤 화면은 16px, 어떤 화면은 18px이었고, 상세 화면의 팀·회원 이름은 정해진 단계에 없는 22px이었어요.

이제 어드민의 글자 크기 **241곳이 전부 토큰**을 씁니다. 대부분은 보이는 크기가 그대로이고, 정해진 단계 밖이던 21곳만 가장 가까운 단계로 옮겼습니다 — 모달·섹션 제목은 17px로, 상세 화면의 팀·회원 이름은 20px로, 하위 제목 하나는 15px로요.

덕분에 "직접 쓴 픽셀 값" 검사의 기준선이 466곳에서 178곳으로 줄었습니다. 이 기준선은 다시 늘어나지 못하게 막는 장치라, 앞으로 어드민에 픽셀 값을 새로 적으면 바로 걸립니다.
