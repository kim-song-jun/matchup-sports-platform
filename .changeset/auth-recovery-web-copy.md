계정 찾기 결과가 실제 로그인 수단을 따라요. 카카오·Apple로 가입한 계정은 로그인 첫 화면의 해당 버튼으로, 이메일 계정은 이메일 로그인과 비밀번호 재설정으로 안내해요(수단이 여럿이면 모두 보여 줘요). 로그인 추가 인증 화면에는 메일이 오지 않을 때 쓸 소셜 로그인·비밀번호 재설정 안내를 더했고, 휴대폰 인증 화면(`/my/phone-verify`)에서 번호가 다른 계정에 있으면 출구 없는 오류 대신 로그인·계정 찾기 안내를 보여 줘요. 로그아웃(설정의 로그아웃 버튼·소셜 가입 나가기·휴대폰 인증 번호 중복 출구)은 하나의 공용 경로로 합쳤어요. 로그아웃 요청이 실패하면 로그인 화면으로 보내지 않고 이유를 알려요.
