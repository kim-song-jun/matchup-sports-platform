채팅 + 패널에 "파일" 보내기를 추가합니다. PDF·워드·엑셀·파워포인트·한글·텍스트·CSV·ZIP 파일을 10MB까지(하루 50MB) 보낼 수 있고, 말풍선의 파일 카드를 누르면 내려받습니다. 파일은 공개 주소 없이 저장돼 그 채팅방 참여자만 받을 수 있고, 한글 파일 이름이 그대로 유지됩니다. 서버는 확장자와 실제 내용을 함께 확인해 실행 파일 등은 거절합니다. 서버는 업로드 자산에 원래 이름 칸, 채팅 메시지·업로드 종류에 `file` 을 추가합니다(추가만 하는 마이그레이션).
