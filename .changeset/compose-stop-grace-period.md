배포로 컨테이너를 다시 만들 때 워커와 API 가 정리할 시간을 충분히 주도록 종료 여유(`stop_grace_period`)를 워커 30초 · API 60초로 정해요. 기본 10초 뒤에 강제 종료(SIGKILL)되면 워커의 일감 비우기(최대 20초)와 API 의 관리자 대진 트랜잭션(최대 45초)이 잘리기 때문이에요. 데이터베이스 연결 끊기는 HTTP 서버가 진행 중 요청을 마친 뒤(`onApplicationShutdown`)에 하도록 옮겨서, 늘린 여유 안에서 진행 중 요청이 끝까지 가요. 여유가 앱의 정리 시간보다 짧아지면 CI 가 잡아요.
