설정 화면과 선수 카드에서 같은 말이 두 번 나오던 부분을 정리했어요.

`/my/settings/{player-card,tournament-real-name,notifications,record-consent,theme}` 5개
화면은 "설명 카드 + 조작 카드"로 나뉘어 있어서 같은 제목이 두 번 보이거나(예: "선수 카드
숨기기") 비슷한 문구가 카드 두 개에 걸쳐 반복됐어요. 이제 화면마다 분류 라벨 하나 +
조작 카드 하나로 합치고, 설명 문장은 카드 아래 각주 한 줄로 옮겼어요.

첫 경기 전(잠긴 능력치가 있는) 선수 카드는 뒷면 잠긴 능력치 6줄이 같은 해제 조건 문구를
여러 번 반복했어요(예: "후기 3개를 받으면 열려요"가 실력·매너·시간약속 세 번). 이제 같은
조건끼리 묶어 조건 문구는 한 번만 보여줘요. 카드 아래 진행 박스는 "능력치 0 / 6 열림"처럼
숫자만 남겼고, 카드 아래 한 줄 요약에서 등급 산식을 또 말하던 "경기 수로 올라가요"도
지웠어요(카드 아래 진행 박스·카드 뒷면이 이미 같은 말을 해요). 뒷면 성향 칩은 2열 격자
대신 가운데 정렬 줄바꿈으로 바꿔 칩 개수가 홀수여도 마지막 칩이 혼자 남지 않아요.
