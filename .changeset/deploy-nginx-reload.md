배포할 때 nginx 컨테이너를 다시 만들지 않고 설정만 다시 읽게 했어요. 지금까지는 배포마다 nginx 를 새로 만들어 그동안(약 11초) 화면과 API 가 503 이었어요. 이제 nginx 가 릴리스마다 바뀌지 않는 폴더를 마운트하고, 배포가 그 안의 설정·릴리스 헤더·정적 파일을 바꾼 뒤 `nginx -t` 로 확인하고 reload 해요. nginx 이미지·마운트·포트가 바뀐 배포와, 이 방식 전에 만든 릴리스로 되돌릴 때만 컨테이너를 다시 만들어요. 운영과 alpha 의 배포·실패 복구·롤백이 같은 방식을 써요.
