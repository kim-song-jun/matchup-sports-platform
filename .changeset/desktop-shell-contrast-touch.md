데스크톱 공통 셸(GNB·푸터)의 대비·히트박스 4건을 고칩니다.

alpha 실측(2026-09-08) 결과 **데스크톱 5화면 전부**에서 같은 4건이 기준 미달이었고,
모바일에는 0건이었습니다 — 데스크톱 전용 `_shell.css` 한 파일이 뿌리입니다.

| 요소 | 전 | 후 |
|---|---|---|
| 활성 GNB 탭 | `--blue500` 3.71:1 | `--blue700` 5.41:1 |
| 푸터 태그라인 | `--grey500` 2.91:1 | `--grey700` |
| 푸터 카피 | `--grey400` **1.92:1** | `--grey700` |
| 브랜드 링크 | 100×27px | `min-height: 44px` |

넷 다 **같은 파일 안에 이미 고쳐진 형제**가 있었습니다 — `footer-links a` 는 같은 지면
(`--grey50`)에서 grey700 으로 올리며 이유를 주석으로 남겼고, `nav-avatar` 는 36px 박스로
히트박스를 확보했습니다. 옆줄만 빠져 있었습니다. 새 색·새 패턴을 만들지 않고 그 값을 그대로 씁니다.

푸터 워드마크(3.55:1)는 **건드리지 않았습니다** — 로고타입은 WCAG 1.4.3 예외 여지가 있어
별도 판단이 필요합니다.
