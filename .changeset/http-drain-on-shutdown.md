배포 때 웹과 API 가 종료 신호를 받고도 바로 내려가지 않고 유예 시간(웹 30초·API 60초)을 다 채운 뒤 강제 종료되던 문제를 고쳤어요. Node 서버는 닫는 중에도 nginx·웹이 계속 다시 쓰는 keep-alive 연결에 응답을 이어 가서 닫히지 못했어요. 이제 종료 신호를 받으면 처리 중 요청은 끝까지 응답하고, 그 뒤의 응답에는 `Connection: close` 를 붙여 연결을 정리해요. 또 웹이 2개일 때 API 를 바꾼 직후 nginx 가 새 API 주소를 바로 읽어서, 웹 교체가 끝날 때까지 API 요청이 실패하는 구간이 생기지 않아요. 화면과 API 응답은 그대로예요.
