리그전 전수 검수(8차원 코드 리뷰 + alpha 라이브 프로브 + 적대 검증)에서 확정된 결함 일괄 수정.

- 커널: 더블 라운드로빈 2회전에서 같은 페어의 홈/어웨이가 뒤집히지 않던 결함 수정(재회 시 직전 방향 반전) — 홀수 팀 홈 경기 수 불균형도 함께 해소
- 어드민 API: 비활성 팀 포함 대진 생성 500 → 422, 대형 리그 트랜잭션 타임아웃 명시, 종료일<시작일 검증, regionId 사전 검증, 팀 순서 비결정성 제거
- 공개 API: 취소 대진의 pendingFixtures 영구 집계 제외, 득점/도움 순위에서 0골/0도움 선수 제외, 비-UUID 리그 ID 에러를 DOMAIN_CODE 규약으로
- 팀매치: 내 경기 status 필터 실동작, 커서 페이지네이션 유일 tie-breaker 추가, 리그 대진의 호스트 일방 취소 차단(409)
- 프론트: 어드민 대진/공개 순위 화면 로딩·에러 상태 추가(영구 빈 화면 해소), 내 경기 리그전 배지 렌더, blur 시 무변경 PATCH 차단
- 테스트: 홈/어웨이 뒤집기 전수 단언, 3팀 순환 동률 커버, 어드민 비인가 401/403 네거티브, 버그 박제 단언 교정
