화면이 **모르는 값을 지어내지 않게** 했어요 — 목록·상세 전반의 목업 유출 정리.

화면 골격을 잡으려고 만들어 둔 목업(`*.view-model.ts`)이 API 응답의 **폴백**으로 쓰이고 있었어요. 그래서 API가 어떤 칸을 안 주면, 실제 매치·팀 카드에 **다른(가짜) 개체의 값**이 그대로 붙었습니다. 팀 매치의 "매너 4.8 · 승 23"이 대표적이었고, 같은 구조가 여러 화면에 남아 있었어요.

정리한 곳과, 대신 보여주는 것:

- **매치 카드·상세**: 레벨·성별·지역은 '레벨 미설정'·'성별 미설정'·'지역 미정'으로, 호스트는 '호스트'로. 인원을 못 읽으면 목업 인원(18/22명)이 아니라 0. 상세 주소는 폴백이 걸리면 **다른 매치의 실제 주소**를 이 매치 주소처럼 보여줬는데, 이제 빈 값으로 둡니다.
- **팀 상세**: 소개·태그·다음 일정에 목업 팀의 문구('오늘 21:00 정기전', '주 1회 정기적으로 풋살을 즐기는 동네 팀이에요')가 붙지 않아요. 소개가 없으면 그 팀의 실제 지역·종목으로 만든 문장을 씁니다.
- **팀 매치**: 호스트팀 이름·경기장·지역이 목업('FC 발빠른놈들')으로 채워지지 않아요. 비용은 호스트가 안 적었으면 **'비용 미정'** 으로 두고, 0원으로 단정해 '무료초청' 배지를 붙이지 않습니다.
- **홈**: 추천·대표 매치 카드를 목업 카드 위에 얹지 않아요. 종목 아이콘·장소·인원이 다른 매치의 것으로 남던 문제입니다.
- **팀 멤버 관리**: 팀 정보를 불러오는 동안 목업 팀 이름·운영진 수를 보여주지 않아요.

화면 배치는 그대로예요. 값을 모를 때 그 자리를 감추거나 "모른다"고 적을 뿐입니다.
