목업 대회에서 운영 콘솔이 "경기 미생성"으로 뜨던 문제 수정. 픽스처만 만들고 `V1Game` 을 만들지
않았다 — `V1Game` 은 `fixture-game-backfill` 이 만드는데 그 백필은 배포 때 한 번만 돌고,
`competitionConfigVersionId` 가 없는 픽스처는 `CONFIG_MISSING` 으로 격리한다. 이제 대회·픽스처에
ACTIVE config 를 박고 생성 직후 백필을 직접 돌린다.

목업 패널 UI 개선: 지금 쓸 수 있는 테스트 팀 수와 만들 수 있는 최대 팀 수를 미리 보여주고,
상한을 넘기면 입력 옆에서 바로 알려주며 버튼을 잠근다(눌러 보고 400 을 받아야 알던 것을 없앴다).
생성 결과에 운영 콘솔 준비 경기 수도 함께 표시한다.
