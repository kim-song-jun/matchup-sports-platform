Prisma 가용성 실패(커넥션 풀 포화·트랜잭션 시작 실패)를 500 대신 503 + `SERVICE_TEMPORARILY_BUSY` + `Retry-After` 로 응답한다.

요청 자체는 멀쩡하고 잠시 뒤 그대로 다시 보내면 성공하는 실패인데, 지금까지는 코드 없는
500 `INTERNAL_ERROR` 로 나가 운영자가 장애와 혼잡을 구분할 수 없었다. 혼잡은 코드 결함이
아니므로 로그도 error 가 아닌 warn 으로 남기되(알람 오탐 방지), 원인 추적을 위해 스택은
그대로 적재한다.

행 경합(`40001`/`P2034` 등)은 도메인마다 뜻이 달라 이 변경의 대상이 아니다 — 각 서비스가
`isCommandConcurrencyConflict` 로 409 로 번역하는 기존 경로를 그대로 둔다.
