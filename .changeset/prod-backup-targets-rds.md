운영 DB 일일 백업이 실제 운영 DB(RDS)를 뜨도록 고쳤어요. 예전 스크립트는 서버 안의 옛 DB 컨테이너만 떠서, 앱이 쓰는 DB 는 백업되지 않았어요. 이제 실행 중인 API 와 같은 접속 정보로 일회용 클라이언트가 덤프를 뜨고, 목차를 확인한 뒤에만 S3 `pg/daily/` 에 올려요. 운영 compose 에서는 쓰지 않는 DB 컨테이너 정의를 빼고 alpha 오버레이로 옮겼어요. 운영 런타임 설정에 DB 호스트가 비어 있으면 배포가 시작 전에 멈춰요. alpha 동작은 그대로예요.
