QA 피드백 6건을 반영한다.

- 팀 상세에서 들어간 멤버 프로필·내 리그 화면의 뒤로가기가 팀 목록·리그 목록이 아니라
  그 팀 상세로 돌아오게 한다(`?from=` 출처 + `ShellOverride.backHref`).
- 매치·팀 목록 필터에 지역(시/도) 칩을 추가한다. 시/도를 고르면 하위 구/군까지 함께
  담기도록 서버 조회 조건(`region: { OR: [{id}, {parentId}] } }`)도 같이 넓힌다.
- 팀매치 목록 필터에 전체/일반 팀매치/대회·리그 경기 구분을 추가한다.
- 대회 목록 API에 `genderCategory` 조건을 추가하고 필터에 성별 칩을 붙인다.
- 팀 상세화면에서 비회원에게는 팀 기본 정보를 매치·리그 정보보다 먼저 보여주고,
  기존 팀원·운영진에게는 기존 순서를 유지한다.
- 종료된 대회 결과의 결승·4강·3·4위전 카드를 조별리그와 동일하게 경기 상세 기록으로
  연결한다.
