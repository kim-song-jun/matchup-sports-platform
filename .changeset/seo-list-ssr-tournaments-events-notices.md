대회(`/tournaments`)·이벤트(`/events`)·공지(`/notices`) 목록이 이제 서버에서 첫 페이지를 그려요. 지금까지는 자바스크립트를 실행해야 목록이 나타나서, 스크립트를 돌리지 않는 검색·AI 크롤러는 이 세 페이지를 빈 스켈레톤으로 봤습니다.

서버가 받은 첫 페이지는 화면의 React Query 에 placeholder 로만 넘겨요 — 실제 요청은 그대로 돌고, 필터·더 보기·페이지 번호 동작은 바뀌지 않습니다. 필터가 걸린 주소(종목·상태·성별)는 서버가 목록을 받지 않아요. 무필터 목록을 필터 결과처럼 보여 주지 않기 위해서예요. 서버 요청이 실패하면 "대회가 없어요" 같은 빈 상태 대신 기존 로딩 화면으로 넘어갑니다.

세 목록에 화면에 보이는 카드와 같은 순서·같은 이름의 `ItemList` 구조화 데이터를 붙였고, `/tournaments?kind=league` 는 "정규 리그" 전용 제목·설명을 씁니다(대표 주소는 `/tournaments` 그대로). 공지 날짜와 이벤트 신청 마감일은 서버(UTC)와 브라우저가 같은 날을 그리도록 한국 시간으로 고정했어요.

매치(`/matches`)·팀매치(`/team-matches`)·팀(`/teams`) 목록도 같은 방식으로 서버가 첫 페이지를 그려요 — 지금까지 이 세 화면의 서버 목록은 실제로는 한 번도 나가지 않았어요. 서버 요청이 실패하면 "…가 없어요" 대신 로딩 화면으로 넘어가고, 필터 없는 주소에는 카드와 같은 순서의 `ItemList` 도 붙어요.
