참가가 확정된 뒤 참가 명단(선수·등번호)을 고치러 가는 길을 더 만들었어요. 대회·리그 상세 제목 아래에 "우리 팀 참가" 카드가 생겨요. 카드는 우리 팀 신청 상태와 선수 수를 보여 주고, [명단 수정]을 누르면 명단 화면으로 바로 가요. 지금은 고칠 수 없는 명단(잠금·제출 마감·종료)이면 [명단 보기]와 그 이유를 보여 줘요. 제출 마감이나 잠금으로 막힌 팀장에게는 [다음 경기 명단]도 같이 보여 이번 경기에서 빠질 선수를 바로 뺄 수 있어요. 팀원에게는 [명단 보기]만 보여요. 카드는 명단 화면과 같은 규칙으로 고칠 수 있는지 판정해요. 리그 상세에 있던 [내 신청]은 이 카드로 합쳤어요.

경기 명단 화면의 출전 목록 끝과 경기 상세 "우리 팀 출전" 카드 아래에도 참가 명단으로 가는 줄을 두었어요. 이 줄은 팀장·매니저에게만 보여요.

팀 상세의 "내 리그"가 팀원에게는 "참가 중인 대회·리그"로 바뀌어요. 대회와 리그가 한 목록에 나오고, 줄마다 신청 상태와 선수 수, 명단을 고칠 수 있는지가 보여요. 팀장·매니저가 명단을 고칠 수 있으면 [명단 수정], 그 밖에는 [명단 보기]가 보이고, 누르면 참가 명단 화면으로 바로 가요. 종료되거나 취소된 대회는 맨 아래에 있어요. 신청 상태는 팀 내부 정보라 비회원에게는 지금처럼 공개 리그 목록만 보여요. 이 목록을 위해 `GET /teams/:teamId/competition-entries` API 를 새로 만들었어요. 팀 활성 멤버만 부를 수 있고, 명단 수정 가능 여부는 명단 수정 API 와 같은 판정을 써요.

대회 상세에서 우리 팀이 이미 신청했으면 하단 고정 [내 신청 보기]와 데스크톱 오른쪽의 같은 버튼을 숨겨요. 그 자리는 제목 아래 "우리 팀 참가" 카드가 맡아요. 모바일에서는 하단 버튼이 빠진 대신 위쪽 대진 입구가 보여요. 신청하지 않은 팀에게 보이는 [참가 신청하기]와 [다시 신청하기]는 그대로예요.
