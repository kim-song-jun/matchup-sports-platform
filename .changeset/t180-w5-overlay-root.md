페이지 안에서 여는 시트·대화상자(알림 상세, 멤버 관리 ⋯, 매치 관리, 등번호 넣기, 매치·팀매치 필터, 채팅방 메뉴 등)가 상단바·탭바·매치 만들기 버튼·데스크톱 메뉴 아래에 깔리던 문제를 고쳐요. 페이지 전환 래퍼가 늘 스태킹 컨텍스트가 되던 원인(상시 view-transition-name, 폴백 애니메이션의 fill both)을 없앴고, 페이지 전환 애니메이션은 그대로예요. 개인 매치·팀매치·팀·대회 필터 시트의 [닫기][적용하기] 줄은 시트 바닥에 고정돼 옵션이 많아도 늘 보여요. 확정된 친선 결과를 운영자가 정정할 때 득점 삭제·변경 되돌리기 앞에 확인 창을 띄우고, 정정된 결과는 "운영팀이 정정한 최종 결과"로 표시해요(기록 응답에 officialCorrected 추가). "명단에서 나 찾기"는 명단이 아직 없을 때 "아직 제출된 참석명단이 없어요"라고 알려 줘요(후보 목록 응답에 rosterCount 추가).
