D10 — 시즌 시작 시각 리그 명단 자동 확정 (Task 164 BE-4b).

리그 생성 시 두 잡을 예약한다: 시작 24시간 전 리마인더, 시작 시각 자동 확정. 명단 미제출
팀의 명단을 **자격을 통과한 멤버**로 채우고 `rosterAutoConfirmedAt` 을 남긴다(정원 초과는
가입 순 상위 N명, 통과자 0명이면 명단을 만들지 않고 실패를 통보).

**기본은 꺼져 있다.** `DISABLE_LEAGUE_ROSTER_AUTOCONFIRM_CRON=false` 를 명시적으로 넣어야
실행된다 — 켜는 것은 데이터 자동 쓰기를 시작하는 것이라 승인 대상이다.
