팀 활동 요약이 같은 말을 두 번 하던 것을 고칩니다.

`formatTeamActivitySummary` 가 구조화된 값(요일·시간대·빈도·유형)과 팀이 직접 쓴 메모를
그대로 이어붙이고 있었습니다. 메모가 구조화된 값을 다시 말하는 경우가 흔해서, alpha 실측
(2026-09-07) 결과 활동 줄 **7개 중 4개**가 중복이었습니다.

```
요일 '수·일' + 시간대 '저녁' + 메모 '매주 수·일 저녁 · 서울 송파구'
→ "수·일 · 저녁 · 매주 수·일 저녁 · 서울 송파구"
```

메모가 이미 담고 있는 구조화된 조각은 빼고 메모를 남깁니다 — 메모 쪽이 더 구체적입니다
(위 예에서 `매주`·`서울 송파구` 는 구조화된 값에 없습니다).

비교 대상은 **우리가 만든 라벨**이고 그것이 메모에 그대로 들어 있는지만 봅니다 —
임의 문자열의 모양을 짐작하지 않습니다.
