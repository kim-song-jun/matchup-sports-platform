팀 카드의 조건 태그가 줄바꿈해 카드가 커지던 것을 고칩니다.

레벨 태그는 서버가 자유 텍스트로 줍니다. alpha 실측(2026-09-07)에서
`중급 · 빌드업과 패스 플레이 중심`(17자, **170px**)처럼 문장이 들어온 팀이 50곳 중 4곳
있었고, 태그 행 폭이 **232px** 이라 `170 + gap 8 + 성별 무관 62 = 240px` 로 8px 넘쳐
형제 배지가 둘째 줄로 밀렸습니다 — 카드가 32px 커집니다.

태그 폭을 **62%** 로 묶어 형제 배지 자리를 남깁니다. 상한은 넘칠 때만 걸리므로 짧은 태그
(`입문-고수`·`초보`)는 그대로입니다. 잘림은 CSS 가 하고 텍스트는 DOM 에 남아 스크린리더는
전문을 읽습니다.
