팀 매치 카드에 보이던 **가짜 전적**을 실제 값으로 바꿨어요.

지금 프로덕션에서는 어느 팀 매치를 열어도 "매너 4.8 · 승 23"이 똑같이 보입니다. 팀 매치 목록·상세 API 가 팀 통계를 아예 안 내려줘서, 화면이 골격용 목업 숫자를 그대로 채워 왔거든요. 실제로 잘하는 팀도, 오늘 만든 팀도 같은 숫자로 보였습니다.

- **API 가 진짜 값을 내려줘요.** `GET /team-matches` 와 `GET /team-matches/:id` 응답의 `hostTeam` 에 `mannerScore`(공개된 팀 후기만 집계)와 `wins`(현재 확정본 기준 `WON` 전적 수)가 추가됐어요. 목록은 배치 1회로 모아 읽어 N+1 을 만들지 않습니다.
- **모르는 값은 지어내지 않아요.** 공개된 후기가 없어 매너 점수를 낼 수 없으면 목업 숫자로 채우지 않고 그 줄을 감춥니다. 0 으로 채우면 "매너 0점"이라는 새 거짓말이 돼요.
- **홈 바로가기 순서**: 팀매치를 개인 매치보다 앞에 둡니다.
