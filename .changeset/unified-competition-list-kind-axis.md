대회 목록에 유형 축(전체 / 정규 대회 / 정규 리그)을 붙이고, 리그가 대회 화면에 섞여도
자기 정보만 보이도록 정리했다.

- `/tournaments` 가 `?kind=all|tournament|league` 를 읽는다. 쿼리가 없으면 **전체**다.
- 유형 세그먼트가 "대회 목록" 제목 아래·종목 칩 위로 옮겨졌다(이동 메뉴 → 필터).
- 리그 카드에 "리그" 배지가 붙는다. 대회와 상태 배지 글자가 같아 구분이 안 되던 자리다.
- 리그에 개념이 없는 것들을 안 그린다 — **정원**(스키마 기본값 8) · **참가비**(기본값 0 →
  "무료") · **성별**(null → "성별 구분 없음"). `V1League` 에 그 필드들이 아예 없다.

`/league-matches` 는 그대로 살아 있다 — 리다이렉트는 별도 변경이다.
