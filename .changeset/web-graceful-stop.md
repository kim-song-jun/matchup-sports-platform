웹 컨테이너를 교체하거나 웹 2개로 운영할 때 요청이 끊기지 않도록 고쳤어요. 실시간 연결(Socket.IO 폴링·WebSocket)이 웹 컨테이너를 거치면 종료 신호를 받은 웹이 진행 중 요청을 끝내고도 닫히지 못해 Docker 유예 시간 끝에 연결이 한꺼번에 끊기고, 폴링 POST 는 nginx 가 다른 웹으로 다시 보낼 수 없었어요. 이제 nginx 가 `/socket.io/` 를 웹을 거치지 않고 API 로 바로 보내요. 웹 종료 유예 시간은 30초로 명시했어요. 화면과 API 동작은 그대로예요.
