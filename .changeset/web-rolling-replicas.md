웹 컨테이너를 2개까지 둘 수 있게 해요. 설정 값 `V1_WEB_REPLICAS`(운영 기본 1, alpha 기본 2)가 2 이면 배포가 웹 컨테이너를 하나씩 다시 만들고 healthy 를 기다린 뒤 다음으로 넘어가서, 배포하는 동안에도 한쪽이 요청을 받아요. nginx 는 두 웹으로 나눠 보내고 한쪽이 죽었거나 재시작 중이면 다른 쪽으로 넘겨요. 개수 1 일 때는 지금과 같은 명령으로 동작해요. 운영은 4GB 서버로 올린 뒤에 `.env` 에 `V1_WEB_REPLICAS=2` 를 넣어 켜요.
