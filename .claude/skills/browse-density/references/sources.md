# 근거 — 두 영상에서 확인한 것

자막만 읽고 규칙을 세웠다가 배치·크기 기준을 통째로 놓친 적이 있다(2026-09-04).
두 영상 모두 **프레임을 뽑아 화면을 직접 확인**한 뒤 정리했다.

## 영상 1 — 랜딩 (`pCc9GspeYfg`, 13분 45초)

제목은 "6가지 방법"이지만 챕터는 여덟이다.

`01 서비스 이해도` · `02 레이아웃 리듬감` · `03 그래픽 기본 개념` · `04 그래픽 삼각 구도` ·
`05 그래픽 공간감` · `06 컬러 및 빛의 이해` · `07 여백 개념` · `08 마무리 디테일`

이 영상의 규칙은 **읽는 화면 전용**이다. `landing-rhythm` 스킬이 담고 있다.
목록에 그대로 가져오면 밀도가 깨진다 — 이 스킬이 존재하는 이유다.

## 영상 2 — 커머스 목록·상세 (`CYhJxtcL5B0`, 17분 10초)

같은 채널의 라이브 작업 영상. 나이키형 상품 목록·상세를 Figma 로 짜면서 나온 판단들이다.
화면에서 직접 확인한 것:

- **"화면 영역을 조금 더 좁게 써야 된다"** — 목록은 여백보다 비교 가능한 개수가 먼저다.
- **"밑에 항목을 볼 수가 없잖아요"** — 필터를 목록 위에 쌓으면 결과가 가려진다.
- **"스크롤할 때 버튼이 밑에 붙어서 따라다녀야 되고요"** — 적용 버튼은 스크롤과 무관하게 닿아야 한다.
- **"상단으로 가져가는 전략이 있고요 / 어떤 전략을 가져가냐에 따라 다른 거예요"** —
  필터는 상단 칩과 좌측 레일 중 하나를 고르는 문제이지 둘 다 두는 게 아니다.
- 최종 결과물은 **4열 조밀 그리드**: 정사각 이미지 → 색상 스와치 → 상품명 1줄 →
  스펙 2줄(작게) → 가격 + 원가 취소선 + 할인율. 텍스트 블록이 매우 촘촘하다.
- 참고로 띄운 실서비스(지그재그·무신사·BEAKER)도 전부 조밀한 그리드였다.
