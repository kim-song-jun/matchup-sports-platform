# 섹션 모듈

모든 소개 섹션은 아래 네 칸을 같은 순서·같은 간격으로 반복한다. 핀테크 랜딩(토스·카카오페이)이 쓰는 기본 모듈이다.

```
┌──────────────────────────────┐
│ 키워드        (label 13px, --blue700, 600)   │ ← 카테고리 라벨. 2~6자
│ 타이틀        (heading 24px, 700, ≤2줄)      │   margin-top 8
│ 본문          (body 15px, --text-muted, ≤2문장)│   margin-top 12
│                                              │   margin-top 24
│ ┌──────────────────────────┐                 │
│ │      그래픽 영역          │ (tint-blue / grey50 카드, radius-hero) │
│ │   이미지는 카드 폭 60~70% │                 │
│ └──────────────────────────┘                 │
│ [추가 정보가 있으면 여기, 맨 아래]            │   margin-top 16
└──────────────────────────────┘
                                    섹션 간 48px+
```

## 토큰 매핑 (v1_web)

| 칸 | 클래스/토큰 |
|---|---|
| 키워드 | `.tm-text-label`, `color: var(--blue700)`, weight 600 |
| 타이틀 | `--font-size-heading`(24) 이상, weight 700, `letter-spacing -0.01em`, `line-height 1.3` |
| 본문 | `.tm-text-body`(15) 또는 `--font-size-body-lg`(17), `color: var(--text-muted)`, `line-height 1.55` |
| 그래픽 영역 | 배경 `var(--tint-blue)` 또는 `var(--grey50)`, `border-radius: var(--radius-hero)`(24), 정사각 또는 4:3, 안쪽 여백 `--spacing-6`(24) |
| 섹션 여백 | 위아래 `--spacing-12`(48) 이상. 히어로는 64 |
| 가로 여백 | `var(--v1-shell-page-x)`(20, 360 이하 16) |
| 강조 섹션 | 배경 `var(--grey50)`. 한 화면에 **하나만** |

랜딩 전용 클래스는 `apps/v1_web/src/app/desktop/landing.css` 의 `.tm-landing-*` 에 모여 있다. 새 섹션을 만들 때 기존 `.tm-landing-section`, `-section-inner`, `-section-header` 를 먼저 재사용하고, 없는 것만 추가한다.

## 히어로 (첫 화면)

- 타이틀은 모듈의 타이틀보다 한 단계 크다(28~32px, 700). 서비스가 뭔지 한 문장.
- 서브 문장은 1개. 그 아래 주요 CTA 1 + 보조 CTA 1.
- 그래픽 영역은 타이틀 **아래**. 타이틀보다 시각 무게가 커지면 안 된다 — 그래픽이 먹는 세로 높이는 뷰포트의 40% 이하.
- 통계 숫자(가입 팀 N 등)를 넣으려면 히어로 맨 아래, 3개 이하.

## 카피 예시 (Teameet)

| 키워드 | 타이틀 | 본문 | 그래픽 메시지 |
|---|---|---|---|
| 팀 매칭 | 우리 팀 실력에 맞는 상대를 찾아요 | 지역과 실력대를 고르면 비슷한 팀이 보여요. 신청부터 확정까지 채팅 한 곳에서 끝나요. | 함께·소속 → 저지 두 벌 |
| 대회 운영 | 대진표부터 결과까지 한 번에 | 조 편성, 일정, 기록을 운영자가 직접 입력해요. 참가 팀은 실시간으로 확인해요. | 성과 → 트로피 |
| 기록 | 경기가 쌓이면 실력이 보여요 | 팀 전적과 개인 기록이 자동으로 정리돼요. | 성장 → 로켓 |

## 점검표 (구현 후)

- [ ] 모든 섹션의 키워드·타이틀·본문 간격이 같다(computed margin 을 읽는다)
- [ ] 그래픽 영역 카드의 radius·배경이 전 섹션 동일
- [ ] 색 깐 섹션이 정확히 하나
- [ ] 390 폭에서 타이틀 2줄 이내, 본문 3줄 이내
- [ ] 주요 CTA 1개, 바텀 고정 CTA 없음
- [ ] 다크 모드에서 그래픽 영역 배경이 `--tint-blue`/`--grey50` 의 다크 값으로 바뀐다
