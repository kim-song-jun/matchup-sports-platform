# 대회 운영사에 체험 전달하기

공유 주소: `https://alpha.teameet.co.kr/tournament-ops-demo`

> Alpha 배포·실측 상태는 [시나리오](../scenarios/tournament-ops-demo.md)를 따른다. 이 가이드는 기능 PR #2103의 체험 전용 화면을 설명한다.

## 전달 문구

Teameet의 대회 운영 흐름을 직접 체험해 보실 수 있는 링크를 전달드립니다.
로그인 없이 약 5분 동안 샘플 대회 준비, 참가팀 확인, 대진 구성, 경기 기록과 결과·시상을 따라가실 수 있습니다.
디렉터·기록 담당자·참가자 관점을 바꿔 보실 수 있으며, 실제 대회나 참가자에게 영향을 주지 않는 체험 화면입니다.

## 추천 체험 순서

1. **디렉터**에서 대회명과 장소를 저장하고 샘플 참가팀 4팀을 확정한다.
2. **대진 구성**에서 샘플 대진을 만든다. 4강 2경기와 결승 1경기가 준비된다.
3. **기록 담당자**로 바꿔 배정된 4강 1경기를 연다. 체험용 라인업을 준비하고 경기를 시작한다.
4. 샘플 선수의 득점·경고를 기록한다. 마지막 기록 취소도 확인하고 경기를 종료한다.
5. **디렉터 결과 검토**로 이동해 체험 결과를 확정한다. 동점이면 승부차기 승리팀을 선택한다.
6. MVP를 저장하고 **참가자 화면**에서 확정된 결과와 시상을 본다. 대진 구성에서 결승 자리 반영도 확인한다.

## 체험 범위

- 주요 운영 업무를 설명하는 별도 시뮬레이터이며 실제 운영 콘솔 전체 기능의 복제본은 아니다.
- 모든 선수·팀·경기는 샘플이다. 실제 대회 생성, 참가 신청, 결제, 알림, 공식 결과 API는 실행하지 않는다.
- 체험의 역할 전환은 실제 계정 권한을 부여하지 않는다. 실제 경기 결과 공식 확정은 별도 권한과 운영 정책을 따른다.
- 진행은 브라우저 탭에만 저장되며 새로고침하면 이어진다. 다른 업체·기기와 진행을 공유하지 않는다.
- **공유 링크 복사**는 새 체험을 시작하는 주소만 복사한다. 새 탭으로 받은 사람은 독립적으로 체험한다.
- **처음부터**는 확인 후 현재 탭의 체험만 초기화한다. 실제 개인정보를 입력할 필요가 없다.

## 접근 위치

관리자의 **대회·리그 현장 운영** 상단과 마이페이지의 **담당 대회 운영** 상단에 체험 진입 영역이 있다.
외부 운영사는 관리 화면 권한 없이 위 공유 주소로 바로 들어갈 수 있다.
