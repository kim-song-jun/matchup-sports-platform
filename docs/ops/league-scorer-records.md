# 정규 리그 득점왕·도움왕 운영 가이드

> 2026-08-25 기준. 운영자 결과 입력에 선수별 득점·도움 기록이 추가되면서(U1 확장),
> "기록을 입력했는데 왜 공개 화면에 안 뜨나요?"에 답하는 문서다.

## 1. 기록 입력 — 어디서, 어떻게

- **어드민 > 정규 리그 > 리그 상세 > 대진 표**의 `결과 입력`(미입력 대진) 또는
  `결과 정정`(공식 확정 대진) 모달에 **"득점·도움 기록 (선택)"** 섹션이 있다.
- 팀별 "선수 추가…" 셀렉트에서 선수를 골라 행을 만들고 골·도움 수를 넣는다.
  선수 목록은 대진 생성 시 자동으로 만들어진 게임 로스터(양 팀 전체 active 멤버)다.
- 검증 규칙(서버·화면 동일): 팀별 **득점 합 ≤ 팀 스코어**(자책골 여지로 미만 허용),
  **도움 합 ≤ 기록된 득점 합**. 어기면 제출이 잠긴다.

### 정정 시 기록이 지워지지 않는 규칙 (중요)

- 정정 모달은 **기존 기록을 미리 채워서** 연다 — 화면에 보이는 것이 저장될 전체다.
- API 직접 호출 시: `participants` **미전송 = 기존 기록 승계**, 명시적 `[]` = 삭제,
  전송 = 교체. 스코어를 낮추는 정정이 승계 기록과 충돌하면
  `LEAGUE_RESULT_CARRIED_PARTICIPANTS_CONFLICT`(400)로 거부되니 기록을 함께 다시 입력한다.

## 2. 공개 화면에 뜨는 조건 — 입력만으로는 안 뜬다

리그 상세의 **득점 순위·도움 순위**는 개인정보 보호 설계상 아래 두 조건을 모두
만족한 선수만 집계한다(`isParticipantPubliclyEligible`):

1. **참가자 신원 연동** — 게임 로스터의 참가자 행이 실제 사용자 계정과 연결돼 있어야
   한다(`V1ParticipantIdentityLinkCurrent`).
2. **경기 기록 공개 동의** — 그 사용자가 **마이 > 설정 > 경기 기록 공개**를 켜 둔 상태
   (`V1UserRecordConsent = GRANTED`).

조건을 못 채운 기록이 있으면 순위 빈 화면이 "선수가 신원 연동과 경기 기록 공개에
동의하면 순위가 공개돼요"라고 안내한다(2026-08-25 추가 — `hiddenByEligibility`).

## 3. 운영 절차 제안

1. 리그 개막 공지에 **"마이 > 설정 > 경기 기록 공개"를 켜 달라**는 안내를 포함한다.
2. 신원 연동: 연동 요청·승인 API(`identity-link-requests` + `attest`)는 있으나
   **일반 사용자용 연동 화면은 아직 개발 중**이다(2026-08-25 기준,
   `feat/v1-identity-attest-team-member` 진행 중). 그 전까지는 대회 라인업 경로로
   연동된 선수만 공개 대상이 된다 — 연동 UI가 머지되면 이 문서를 갱신할 것.
3. 기록은 연동·동의와 무관하게 **저장은 항상 된다** — 선수가 나중에 연동·동의를
   마치면 과거 기록까지 소급해 순위에 나타난다(집계가 조회 시점 계산이라 별도
   재처리 불필요).

## 4. 자주 묻는 상황

| 증상 | 원인 | 조치 |
|---|---|---|
| 기록을 넣었는데 순위가 빈 화면 | 선수 미연동 또는 동의 꺼짐 | §3 절차로 유도. 빈 화면 안내 문구로 구분 가능 |
| 정정했더니 기록이 사라졌다 | (2026-08-25 이후에는 발생하지 않아야 함 — 승계 규칙) | 재현되면 버그로 보고 |
| 도움만 넣으려는데 제출이 잠김 | 도움 합 > 기록된 득점 합 | 해당 골의 득점자도 함께 기록 |
