## 사용자 흐름
1. 지정 대회 `/admin/tournaments/ad200600-0000-4000-8000-000000000002/bracket`의 목록 또는 그림에서 **결선 진출팀 배정**.
2. 공식 순위·승점·득실·득점 확인. 조별 진출 수 및 운영자 배정 순서 변경. 공식 순위 표시가 유지되는지 확인.
3. **조별 교차 자동 배정** 또는 **시드순 자동 배정**, 기존 경기 자리의 팀 직접 선택. 선택된 팀을 다른 자리에 고르면 교환.
4. 동일 조 재대결 경고, 미배정/중복 차단, 변경 전후 확인. 동률/조정이 있으면 최종 확인 후 사유와 함께 저장.
5. 재조회에서 팀 및 경기/게임 사이드가 일치하고 경기 시각·장소·승자 연결·조별 성적이 유지되는지 확인.
6. 결과 정정 후 다시 열면 순위 변경 안내가 보이고 기존 결선 배정은 보존되는지 확인.
7. 5조·20팀·12강에서는 기존 **12강 진출팀 자동 배정**을 선택해 기존 선발·성적 비교·직행4 규칙이 유지되는지 확인.
