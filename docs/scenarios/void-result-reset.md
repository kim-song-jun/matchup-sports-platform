# 결과 무효·시작 전 복구

Persona: 플랫폼 운영자/담당 총괄. Alpha ego-lite,390/768/1440. 실제 실행은 이번 QA 소유의 비공개 대회에서만 한다. 사용자 제공 대회는 읽기 전용 조사 대상이다.

1. 부전승 자리를 포함하는 대회에서 시간·구장을 배정하고 경기 결과를 확정한다.
2. 결과 무효를 열어 사유만 입력, 틀린 문구, 앞/뒤 공백을 확인한다. 실행은 비활성이며 취소 POST0이다. 다시 열면 입력이 비어 있어야 한다.
3. 사유와 정확한 `결과 무효` 입력 후 실행한다. 같은 대진 위치에 예정 경기가 생기고 점수/이벤트는 비어 있어야 한다. 팀·부전승 자리·시간·구장·진출 연결·권한 범위는 유지한다.
4. 부전승 편집의 팀/위치 선택이 활성화되고 실제 저장·새로고침에도 유지되는지 확인한다. 시작·새 점수 입력도 이전 이벤트와 섞이지 않아야 한다.
5. 이전 Game·리비전·이벤트 수가 유지되고 감사에 처리자·사유·전후 경기 ID가 남는지 확인한다. 이전 결과는 공식 전적/순위/진출에 기여하지 않아야 한다.
6. 동일 요청 재전송은 같은 replacement를 반환하며 경기·감사 중복0이다. 이후 경기 또는 의존 단계가 시작됐다면409·전체 변경0이다. 감사 저장 실패 때 전체 rollback은 PostgreSQL integration으로 증명한다.
7. 이미 VOID인 이전 경기는 `시작 전으로 복구`에서 같은 확인 절차로 복구한다. 정규 리그는 결과만 무효이며 대진 교체는 하지 않는다.

Status: 구현/로컬 회귀 진행. 실제 PostgreSQL은 CI, Alpha 처리/스크린샷·console/network·3폭은 미실행. QA 종료 시 소유 대회는 비공개·취소 처리하고 임시 자료/프로세스만 정리한다.
