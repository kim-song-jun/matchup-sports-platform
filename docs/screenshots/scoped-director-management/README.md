# 대회 디렉터 Alpha 기준 화면

2026-10-30, Alpha 배포 SHA `d72b59a37793e048be1387d6f63aeb2de38a13e7`.
PR #2101의 변경 전 화면이다. 이 이미지로 새 기능을 PASS 처리하지 않는다.

- 관리자와 일반 테스트 선수는 실제 이메일 로그인 UI로 각각 로그인했다.
- 관리자 Alpha 목업 생성 UI로 새 4팀 대회와 경기 8개를 만들었다. 기존 대회/배정은 변경하지 않았다.
- 일반 선수는 배정 전 담당 목록이 비었고, 첫 대회 디렉터로 배정 후 해당 대회 1개가 표시됐다.
- 기존 동선은 담당 대회 → 운영 보드다. 신규 관리 화면 진입과 10개 섹션 저장은 새 배포 후 검증 대상이다.
- 디렉터는 지원(조회 전용)을 배정할 수 있지만 다른 디렉터 배정 선택지는 없다.
- 지원 계정으로 실제 로그인해 운영 보드를 조회했다. 디렉터가 사유를 입력해 배정을 해제한 뒤 지원 계정은 권한 안내와 HTTP 403을 확인했다.
- 디렉터의 플랫폼 회원 관리 접근은 권한 안내와 `/admin/me` 403으로 거부됐다.
- 390/768/1440 초기 기준 화면에서 document 가로 overflow 없음. 비공개 전환 전 캡처에서 pageerror/HTTP 오류 없음. 비공개 전환 후 기존 운영 화면의 공개 상세 API 404와 일반 제목 fallback을 관측했으며, 배포 후 후속 QA 대상이다.
- 계정·비밀번호·세션은 저장하지 않았다. 로그인 입력은 비에코 stdin으로 받았고 캡처에서 이메일/비밀번호 입력을 마스킹한다.
- 신규 관리 기능: **0/10 섹션, 0/3 viewport**. 변경 전 기준 화면: **3/3 viewport**.

관리자가 디렉터 배정도 해제한 뒤 담당 목록 items=[]와 운영 화면 재진입 403을 확인했다. 디렉터·지원 테스트 배정 2건 모두 해제했다. Headed Chrome PID 2816 / 부모 Node PID 26076은 context/browser close 및 Node 종료로 정리했다. 로컬 web/API 서버는 실행하지 않았다. 사용자는 이번 범위를 PR·변경 전 캡처까지만으로 선택했다.
