- 디렉터의 플랫폼 회원 관리 접근은 권한 안내와 `/admin/me` 403으로 거부됐다.
- 390/768/1440 기준 화면에서 document 가로 overflow 없음. 예상 권한 거부 외 pageerror/HTTP 오류 없음.
