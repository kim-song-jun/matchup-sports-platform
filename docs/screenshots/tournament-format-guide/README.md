## 검증 범위와 절차

페이지 테스트의 비공개 고정 fixture로 React DOM을 생성하고, 저장소의 실제 globals/tokens/desktop CSS를 PostCSS로 처리해 로컬에서 표시했다. 앱 셸·실제 서버·실제 계정은 포함하지 않은 컴포넌트 시각 검증이며 alpha 배포 후 캡처가 아니다.

- 390×900 / 768×900 / 1440×900, Chrome headed, 화면 하단까지 스크롤 후 캡처.
- 세 폭 모두 진행 방식 3단계와 고정 하단 버튼을 스크롤로 확인할 수 있다. 가로 넘침·카드 잘림 없음.
- 390px에서 세 진행 방식의 설명을 각각 확인했다.
- 확인한 브라우저 console error 0. 스타일·폰트는 로컬 자산을 제공했고 캡처 서버 종료 및 viewport 원복 완료.
- 상단 스테퍼로 저장을 건너뛰는 기능 문제는 별도의 실제 페이지 회귀 테스트에서 증명한다. 기존 코드 3건 실패 → 수정본 3건 통과. PATCH가 변경한 format을 전송하고, 성공 뒤 해당 방식의 단계만 표시하는 것까지 검증한다.

제보 사진 속 대회가 실제로 어떤 format으로 저장됐는지는 확인하지 못했다. 이 PR은 그 대회 데이터를 임의 수정하지 않고, 재현 가능한 생성 마법사의 저장 누락 경로를 막는다.
